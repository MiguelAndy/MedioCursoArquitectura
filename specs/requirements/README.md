# 📝 Requirements Specifications

This folder contains the project's requirements written prior to implementation, serving as the basis for software architecture design, domain modeling, and test planning.

## 📁 Files

- [`functional-requirements.md`](functional-requirements.md): System functional specifications, user capabilities, and use-case flows.
- [`non-functional-requirements.md`](non-functional-requirements.md): Quality attributes (performance, reliability, security, maintainability, scalability) following ISO/IEC 25010.
