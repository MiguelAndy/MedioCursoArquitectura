# 🗄️ Data Models & Schemas

This directory maintains domain data schemas, JSON Schema definitions, Entity-Relationship specifications, and database migrations or DDL models.

## 📁 Files & Subdirectories

- `schemas/`: Machine-readable schema definitions (e.g., JSON Schema draft-07/2020-12) used to validate payloads across boundaries.
- [`schemas/item.schema.json`](schemas/item.schema.json): Canonical JSON schema for the Item domain entity.
