# 🧪 Acceptance Specifications (BDD)

This directory contains executable business acceptance criteria written in **Gherkin** (`.feature` files).

In Spec-First development:
1. **Scenarios are Written Before Code**: Behavior is specified using `Given`, `When`, `Then` syntax.
2. **Automated Test Runners**: Frameworks like Cucumber, Behave, SpecFlow, or Playwright read these files directly to drive acceptance and end-to-end tests in `tests/acceptance/`.
3. **Shared Language**: Ensures product owners, architects, and developers share a unified understanding of business rules.

## 📁 Files
- [`features/example.feature`](features/example.feature): Sample Gherkin acceptance test scenario.
