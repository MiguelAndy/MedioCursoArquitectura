# 🏛️ Architecture Decision Records (ADRs)

Architecture Decision Records (ADRs) document significant architectural and design choices made during the project lifecycle, along with their context, rationale, and consequences.

## ✍️ Creating a New ADR

1. Copy [`template.md`](template.md).
2. Name the file using the format: `YYYY-short-descriptive-title.md` (e.g., `0002-use-clean-architecture.md`).
3. Fill out all sections.
4. Update the index table in this file.
5. Submit for team / architectural review.
